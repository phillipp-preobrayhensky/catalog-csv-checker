# Catalog CSV Checker

A small Python utility for checking a price list before import. A demonstration project prepared with AI. It is not presented as a client project or a service already in use.

## What the example demonstrates

- Reading CSV files with Russian names and prices such as `1 200,50`.
- Checking required fields and the number of columns.
- Including all rows with duplicate IDs in a report, without arbitrarily choosing a winner.
- Normalizing whitespace and protecting text fields from being interpreted as formulas when opened in a spreadsheet.
- Separate files for accepted rows, rejected rows and summary counts.
- Leaving the source unchanged and not overwriting an existing output folder.

## Quick start

Requires Python 3.11 or later. No external dependencies or API keys.

```bash
python catalog_check.py examples/products.csv --output result
python -m unittest -v
```

The demo data is expected to contain 9 rows: 5 accepted and 4 rejected. Exit code `2` means processing completed but some rows were rejected. `0` means no rejected rows; `1` means a startup or file structure error.

The header format is fixed: `id;name;price_rub;category`. Encoding: UTF-8 or UTF-8 with BOM. Separator: `;`. Prices must be non-negative, with up to two decimal places. IDs consist of Latin letters, digits, `_` and `-`.

## Limitations

The utility does not correct semantically incorrect prices or remove ambiguous duplicates without a report. Large files, Excel, APIs and online store uploads require additional development. Keep `rejected.csv`: it contains the original data from rejected rows, so it should not be published for real clients.
