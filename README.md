# Catalog CSV Checker

Небольшая утилита Python для проверки прайс-листа перед импортом. Демонстрационный проект, подготовленный с ИИ. Не выдаётся за клиентскую разработку или уже используемый сервис.

## Что показывает пример

- Чтение CSV с русскими названиями и ценами вида `1 200,50`.
- Проверку обязательных полей и количества колонок.
- Выделение всех строк с повторяющимся ID в отчёт, без выбора произвольного победителя.
- Нормализацию пробелов, защиту текстовых полей от формул при открытии в таблице.
- Раздельные файлы принятых строк, отклонённых строк и итоговых счётчиков.
- Исходник остаётся неизменным, существующая папка результата не перезаписывается.

## Быстрый запуск

Нужен Python 3.11 или новее. Внешних зависимостей и ключей API нет.

```bash
python catalog_check.py examples/products.csv --output result
python -m unittest -v
```

На демоданных ожидаются 9 строк: 5 приняты, 4 отклонены. Код завершения `2` означает, что обработка выполнена, но есть отклонённые строки. `0` означает отсутствие отклонений, `1` означает ошибку запуска или структуры файла.

Формат заголовка фиксирован: `id;name;price_rub;category`. Кодировка UTF-8 или UTF-8 с BOM. Разделитель `;`. Цены неотрицательны, до двух знаков после запятой. ID состоит из латинских букв, цифр, `_` и `-`.

## Границы

Утилита не исправляет неверные цены по смыслу и не удаляет неоднозначные дубли без отчёта. Для крупных файлов, Excel, API и загрузки в интернет-магазин нужна отдельная доработка. Сохраняйте `rejected.csv`: он содержит исходные данные отклонённых строк, поэтому его не следует публиковать для реальных клиентов.

## Вклад и использование ИИ

Код и тесты сгенерированы ассистентом по задаче владельца портфолио. Проверены автоматически в среде подготовки. Это учебная демонстрация подхода, без обещания автономной разработки сложных систем.
